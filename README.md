# 🍔 Bun & Bite — Backend API with SQLite Database Integration (P3)

## Overview
Welcome to the **P3 Backend Integration** for **Bun & Bite**, developed as part of the **DecodeLabs Internship Program**. 

This project upgrades the RESTful API from in-memory arrays to a persistent **SQLite Database**. It provides auto-table initialization and full CRUD (Create, Read, Update, Delete) capability for managing restaurant menu data smoothly.
